# 7th Grade Math Gamified Progression System

This document breaks the Grade 7 math curriculum into purchasable progression steps for a gamified learning app. Students earn in-game currency by practicing, completing lessons, watching examples, doing timed tests, and replaying weak skills. They spend that currency to unlock new math "cards," levels, modes, cosmetics, and challenge tiers.

The design goal is simple: students should feel like they are building a powerful math loadout, while the app quietly moves them through TEKS-aligned mastery.

## Currency And Unlock Model

Suggested currencies:

- Coins: earned from normal practice, used for common unlocks.
- Stars: earned from strong level performance, used for mastery gates.
- Tickets: earned from streaks or quests, used for timed challenges.
- Gems: rare currency from boss battles, used for legendary cosmetics or advanced challenge paths.

Suggested rarity levels:

- Common: basic prerequisite skill.
- Uncommon: core 7th grade skill.
- Rare: multi-step or mixed skill.
- Epic: word problems, reasoning, or timed fluency.
- Legendary: unit boss, spiral review, or mastery challenge.

Unlock rule:

Students do not buy correctness. They buy access to harder skills, more problem types, optional challenge modes, and cosmetics. A student can always earn the needed currency through practice, review, or teacher-assigned quests.

## Cross-World Progression Systems

Daily quests:

- Complete 10 rational number problems.
- Earn 6 stars in proportionality levels.
- Watch one example video and solve the "you try" problem.
- Beat one timed level.
- Redo a missed problem set and improve your score.

Weekly boss battles:

- 20 mixed problems from the current unit.
- 5 review problems from older units.
- 1 open-response reasoning problem.
- Rewards: gems, rare cosmetics, title badges, and battle pass XP.

Fake skippable ads:

- "Your brain has been selected for a 90-second timed test. Skip in 5."
- "Double XP available: solve 5 percent problems before the timer runs out."
- "This ad is fake. The practice is real. Want a boss ticket?"

Battle pass rewards:

- Font skins.
- Background themes.
- Avatar frames.
- Answer animation effects.
- Calculator skins.
- Profile titles.
- Bonus challenge tickets.

## Mastery Gate Rules

To unlock a new purchasable skill, students should usually need:

- Enough coins or stars.
- At least 1 star on prerequisite levels.
- Completion of the worked example.
- A short readiness check.

For higher-rarity levels, require stronger proof:

- Rare: 2 stars on prerequisite levels.
- Epic: 3 stars on at least one prerequisite level or teacher unlock.
- Legendary: complete the unit boss readiness quest.

## Recommended App Data Model

Each unlockable math item should have:

- Skill ID
- TEKS alignment
- World
- Level number
- Rarity
- Prerequisites
- Currency cost
- Example video ID
- Worked example ID
- Practice problem pool
- Timed problem pool
- Reward table
- Mastery threshold

Example:

```json
{
  "skillId": "proportionality.unit-rates.level-3",
  "teks": ["7.4D", "7.4E"],
  "world": "Proportional Relationships",
  "level": 3,
  "rarity": "Uncommon",
  "cost": { "coins": 250 },
  "prerequisites": ["proportionality.rates.level-2"],
  "masteryThreshold": { "accuracy": 0.8, "attempts": 10 },
  "rewards": { "xp": 150, "coins": 80, "stars": 1 }
}
```

## Design Caution

The economy should never trap a struggling student. If students cannot afford a required unlock, the app should offer review quests, teacher grants, or practice routes that let them earn the currency without shame. The currency should make progression feel earned, not blocked.
