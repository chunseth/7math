# 6math

The Grade 6 course has 222 playable levels across eight units. A 30-level foundational review leads into seven Grade 6 units with 149 focused levels and 43 mixed-practice levels. Each lesson includes a portrait worked example and 24 practice problems. Guest practice shuffles the pool into two rounds of 12 with the same mix of problem variants. The mixed inequalities lesson requires a first-try graphing answer for a ranked clear. Signed-in players can clear prerequisite lessons, earn stars and rank on the lesson leaderboard.

The sequence covers the Texas Grade 6 mathematics content expectations. Students apply process skills across the units by interpreting models, comparing methods and solving contextual problems. Multi-digit division, coordinate polygons, surface-area nets and mean absolute deviation also draw on the Common Core progression. [Texas mathematics TEKS, §111.26](https://tea.texas.gov/laws-and-rules/sboe-rules-tac/sboe-tac-currently-effect/ch111b.pdf) · [Common Core Grade 6](https://www.thecorestandards.org/Math/Content/6/introduction/)

## Scope and sequence

The map groups levels by skill. Within each skill, each clear unlocks the next level. The mixed-practice level brings those skills together and unlocks dependent topics. Students can study other available branches in parallel.

## Authoring and publication

The original 43 lesson IDs and rankings carry forward as mixed practice. The current candidate revises selected pools while preserving their IDs. Each added level has a separate Grade 6 progress record and leaderboard. The number-line sequence retains Grade 6 one-step practice and has its own examples.

Edit focused-level order and titles in `scripts/6math/progression.txt`, worked examples in `scripts/6math/examples.txt`, and question forms in `scripts/6math/focused.py`. The mixed levels use `scripts/6math/lessons.txt` and `scripts/6math/problems.py`. Run `python3 -B scripts/6math/build.py` to rebuild the bank and guest packs. Run `node scripts/mentalist/ink/render.cjs --grade6` with an H.264-enabled ffmpeg to render the portrait videos and posters.

The map, videos and guest practice ship with the app. To enable ranked play on an existing curriculum database, set the usual `MENTALIST_DATABASE_URL` and `MENTALIST_CONTENT_REVIEWER`, then run `npm run mentalist:publish -- --grade=6 --stage=complete`. This adds release 6005 using the existing schema.
