# 8math

The course follows the standard Texas Grade 8 mathematics sequence in [19 TAC §111.28](https://tea.texas.gov/laws-and-rules/sboe-rules-tac/sboe-tac-currently-effect/ch111b.pdf). The lesson map lists content expectations, prerequisite lessons, and the topics each lesson supports. Process expectations 8.1A–G run across the units through modeling, comparing methods, creating representations, and explaining results. Teachers can extend the guided problems by asking students to write a justification or construct a new example.

The course also includes Grade 8 exponent laws, repeating decimals, function comparisons, transformations, systems and two-way tables from the [Common Core Grade 8 progression](https://www.thecorestandards.org/Math/Content/8/introduction/).

8math has 225 playable levels across eight units. Students can start with 30 foundational review levels, then work through 147 focused Grade 8 levels and 48 mixed-practice levels. Every level has a portrait worked example and 24 practice questions. Guest practice shuffles the pool into two rounds of 12 with the same mix of problem variants. Ranked mixed practice in scatterplots, irrational approximations, and sampling requires a first-try response on that essential skill. Signed-in battles sample 12 questions and use the shared scoring and leaderboard system.

## Scope and sequence

Within a skill, each clear unlocks the next level. Each Grade 8 topic ends with a mixed-practice level. Its clear unlocks the topics that use it as a prerequisite. Foundation branches can be taken independently.

## Content and publication

Each of the 48 original mixed levels retains its level ID and leaderboard. The current candidate updates selected practice pools while preserving their timing targets. The 177 additional levels have their own Grade 8 scores. Of these additions, 58 use reviewed question pools and videos from the original app. The other 119 have new Grade 8 practice and worked examples.

Edit the focused-level order in `scripts/8math/progression.txt`, prerequisite bridges in `scripts/8math/progression.py`, and practice and worked-step rules in `scripts/8math/focused.py`. The mixed levels use `scripts/8math/lessons.txt` and `scripts/8math/problems.py`. Regenerate the bank with `python3 -B scripts/8math/build.py` and use `--check` to verify it. Render the Grade 8 videos with `node scripts/mentalist/ink/render.cjs --grade8` using an H.264-enabled ffmpeg.

The map, guest packs and videos ship with the app. To enable the expanded ranked course, run `npm run mentalist:publish -- --grade=8 --stage=complete` with the usual Supabase connection and reviewer settings. This adds release 8006 to the existing schema. Before publication, sites running release 8001 can still play the original levels with their original prerequisites.
